# ФОЛК — веб-приложение

Веб-версия проекта на React, TypeScript и Vite. Это текущая площадка для разработки интерфейса.

## Запуск

Нужен Node.js и npm. Из корня проекта:

```powershell
cd .\web
npm install
npm run dev
```

Откройте адрес, который напечатает Vite (обычно `http://localhost:5173/`). Для проверки готовой веб-сборки:

```powershell
npm run build
npm run preview
```

Проверка кода: `npm run lint`.

## Что доступно

- Карта курса с шестью разделами и пятью этапами в каждом. Пока доступен первый этап первого раздела; остальные этапы закрыты.
- Четыре последовательных урока первого этапа: новые слова, выбор картинки и перевода, составление фразы, поиск пар и обратная связь.
- Экран выбора языка, результат урока, карточка Маньпупунёра, экран награды, карточки и профиль.

Прогресс хранится только в `localStorage` браузера. При каждом запуске `npm run dev` прогресс сбрасывается, а Vite заново собирает кэш зависимостей. В готовой сборке прогресс сохраняется. Кнопка озвучивания пока служит заглушкой; настоящая запись коми произношения будет добавлена позднее. Дальнейшие уроки и события пока не реализованы.

Статика лежит в `public/`, содержание четырёх уроков — в `src/data/course.json`. Все файлы, необходимые для веб-приложения, находятся внутри `web/`.
