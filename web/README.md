# ФОЛК — веб-приложение

Веб-версия проекта на React, TypeScript и Vite. Это текущая площадка для разработки интерфейса.

## Запуск

Нужен Node.js и npm. Из корня проекта:

```powershell
cd .\web
npm install
npm run dev
```

Откройте адрес, который напечатает Vite (обычно `http://localhost:5173/`). Для проверки готовой веб-сборки:

```powershell
npm run build
npm run preview
```

Проверка кода: `npm run lint`.

## Что доступно

- Карта курса с шестью узлами первой темы, событием Маньпупунёр, второй темой и облаками на продолжении пути.
- Первые два урока первой темы: слова на коми, выбор перевода, карточки, составление фразы и обратная связь. После первого открывается второй.
- Нажатие на остальные закрытые узлы показывает окно о будущем продолжении. Сама надпись на карте не отображается.
- Окно выбора языка, экран завершения, карточка места, разделы нижней навигации.

Прогресс хранится только в `localStorage` браузера. Кнопка озвучивания пока служит заглушкой; настоящая запись коми произношения будет добавлена позднее. Дальнейшие уроки и события пока не реализованы.

Статика лежит в `public/`, содержание двух уроков — в `src/data/course.json`.
