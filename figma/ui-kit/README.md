# UI Kit v3 — генератор для Figma

Плагин за один запуск собирает в вашем файле UI Kit приложения для изучения языков народов России.
Курсы: **коми** и **чувашский**. Маскот — **Лиса**. Палитра — яркая, в духе Duolingo.
Названия у продукта пока нет: когда появится, впишите его в константу `APP_NAME` в начале `code.js`.

## Как запустить (1 минута)

1. Откройте **десктопное приложение Figma** (плагины в разработке запускаются только в нём).
2. Откройте свой файл (лучше чистый).
3. Меню → **Plugins → Development → Import plugin from manifest…** → выберите `manifest.json` из этой папки.
4. Меню → **Plugins → Development → UI Kit · языки народов России**. Через 10–30 секунд внизу появится «✅ … готов».

Если в файле уже есть прошлая версия кита (в том числе с префиксом «Тамыр»), плагин спросит подтверждение и пересоздаст её: удалит свои фреймы, коллекции переменных и стили и соберёт заново. Ваши собственные фреймы и страницы не трогает.

## Как добавить язык

Все данные курсов — в массиве `LANGS` в начале `code.js`. Добавьте объект и перезапустите плагин на чистом файле:

```js
{
  ru: 'Удмуртский', native: 'Удмурт кыл',
  chars: ['ӝ', 'ӟ', 'ӥ', 'ӧ', 'ӵ'],          // буквы сверх русской раскладки
  hello: '…', helloRu: 'Привет!',
  phrase: '…',                              // фраза для упражнения «переведите»
  answer: ['Я', 'изучаю', 'удмуртский'],    // правильный перевод — плитки
  extra: ['читаю', 'дом'],                  // лишние плитки
  typo: '…',                                // пример ошибки без спецбуквы
  picture: '…', pictureRu: 'лиса',
  unit: 'Знакомство и приветствия',
  flag: `<rect width="44" height="32" fill="#…"/>…`, // SVG-содержимое 44×32
},
```

Автоматически появятся: вариант флага, панель спецбукв, строка на «Основах», карточка на онбординге и отдельный экран урока.
Текст карточки «Скоро» — в объекте `SOON`.

## Что появится

**Переменные** (3 коллекции, 76 шт.)
- `UI Kit · Примитивы` — Луг, Небо, Лиса, Мёд, Рябина, Черника, Нейтральные (скрыты из пикеров).
- `UI Kit · Токены` — `color/bg/*`, `color/text/*`, `color/border/*` и роли `primary` (Луг), `secondary` (Небо), `brand` (Лиса), `reward` (Мёд), `danger` (Рябина), `premium` (Черника) — у каждой `default | shadow | muted | subtle`.
- `UI Kit · Размеры` — `spacing/2xs…2xl` (4–48), `radius/sm…full`.

**Стили текста** `UI Kit/…` — 10 стилей. Шрифт Nunito, меняется константой `FONT_FAMILY`.

**Страницы**
- 🎨 Основы — обложка, палитра, токены, типографика, языки курсов со спецбуквами, отступы/радиусы, принципы.
- 🧩 Компоненты — Маскот (4 эмоции), 22 иконки, флаги, кнопки (6 стилей × 3 состояния), метки, счётчики, прогресс, шапка урока, реплика Лисы, плитка слова, клавиша и панели букв, поле ввода, карточки выбора / курса / с картинкой, плашка ответа, итог урока, узел пути, баннер раздела, навигация.
- 📱 Экраны — онбординг, урок на каждый язык (верно / ошибка), главная с учебным путём, итог урока.

## Проверить с носителями
Фразы в `LANGS` — рабочие примеры. Перед релизом покажите их носителям языка:
- коми: «Чолӧм!», «Ме велӧда коми кыв.», «руч» (лиса);
- чувашский: «Салам!», «Эпӗ чӑвашла вӗренетӗп.», «тилӗ» (лиса).

## Если у вас план Starter
- В переменных доступен 1 режим — поэтому без тёмной темы.
- Лимит 3 страницы на файл: если страниц не хватит, плагин сложит всё на первую страницу рядом.
- Белый текст на ярких цветах (как у Duolingo) — используйте только для крупного жирного текста.
