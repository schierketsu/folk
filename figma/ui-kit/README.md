# ФОЛК · UI Kit v8 — генератор для Figma

Плагин за один запуск собирает в вашем файле UI Kit приложения **ФОЛК** для изучения языков народов России.
Сейчас в проекте один курс — **коми**. Маскот — **Лиса**. Палитра яркая, в духе Duolingo, фон экранов белый.
Вся графика по референсу Duolingo: пухлые плоские фигуры, три тона, белые косые блики, серая тень под предметом, светлая тема.

## Как запустить

1. Откройте **десктопное приложение Figma**: плагины в разработке запускаются только в нём.
2. Откройте свой файл.
3. Меню → **Plugins → Development → Import plugin from manifest…** → выберите `manifest.json` из этой папки.
4. Меню → **Plugins → Development → ФОЛК · UI Kit**. Через 10–30 секунд внизу появится «✅ … готов».

Если в файле уже есть прошлая версия кита (с префиксом «Тамыр» или «UI Kit»), плагин спросит подтверждение и пересоздаст её. Ваши собственные фреймы и страницы он не трогает.

## Учебный путь

Путь строится из данных курса в массиве `LANGS` в начале `code.js`. Каждая тема — 6–7 шагов «змейкой»:

```js
units: [
  { title: 'Знакомство и приветствия', color: 'Зелёный',
    steps: ['Звезда', 'Звезда', 'Сундук', 'Наушники', 'Гантель', 'Микрофон', 'Кубок'],
    place: { name: 'Маньпупунёр', sub: 'Столбы выветривания', art: 'manpupuner', task: 'Выучите 6 слов о горах и камнях' } },
]
```

- **Шаги:** Звезда — урок, Книга — история, Наушники — аудирование, Гантель — практика, Микрофон — говорение, Кубок — итог темы, Сундук — награда (золотой, как у Duolingo).
- **Цвет темы:** Зелёный, Синий, Оранжевый или Фиолетовый.
- **Текущий шаг** обведён кольцом из сегментов, по одному на задание внутри шага: пройденные окрашены в цвет темы, остальные серые. Сейчас заданий три (`LESSONS_PER_STEP` в `code.js`), состояния узла — «Текущий 0/3», «Текущий 1/3», «Текущий 2/3».
- **Место** (`place`) стоит сбоку от пути без подписей: картинка и три звезды прогресса. По нажатию открывается лист «Задание места»: широкая картинка, название, подзаголовок, задание и кнопка.
- **Картинки мест:** иконка 120×110 для карты в `ART`, широкая сцена 343×180 для листа в `ART_WIDE`.

## Как добавить язык

Добавьте объект в `LANGS` по образцу коми (`ru`, `native`, `chars`, `hello`, `phrase`, `answer`, `extra`, `typo`, `picture`, `units`, `flag`) и перезапустите плагин. Автоматически появятся вариант флага, панель спецбукв, строка на «Основах», карточка на онбординге и экран урока. Текст карточки «Скоро» хранится в объекте `SOON`.

## Что появится

**Переменные** (3 коллекции, 76 шт.)
- `ФОЛК · Примитивы` — Луг, Небо, Лиса, Мёд, Рябина, Черника, Нейтральные.
- `ФОЛК · Токены` — `color/bg/*`, `color/text/*`, `color/border/*`, роли `primary | secondary | brand | reward | danger | premium`.
- `ФОЛК · Размеры` — `spacing/2xs…2xl`, `radius/sm…full`.

**Стили текста:** `ФОЛК/…`, 10 стилей, шрифт Nunito.

**Страницы**
- **Основы** — обложка, палитра, токены, типографика, курс и спецбуквы, отступы, принципы.
- **Компоненты:**
  - маскот (4 эмоции), иконки, флаги;
  - кнопки, метки, счётчики, прогресс;
  - шапка урока, реплика Лисы, плитка слова, панель букв, поле ввода;
  - карточки выбора, курса и с картинкой;
  - плашка ответа, итог урока;
  - путь: значки шагов, узел пути (4 цвета × 3 состояния), сундук, разделитель темы, баннер темы;
  - места и лист «Задание места»;
  - нижняя навигация, только значки: Нора (путь), Задания, Рейтинг, Лента новостей, Профиль.
- **Экраны:**
  - онбординг;
  - урок «верно» и урок «ошибка»;
  - главная (тема 1), главная (переход к теме 2), главная с открытым заданием места;
  - итог урока.

## Проверить с носителями
Фразы в `LANGS` — рабочие примеры. Перед релизом покажите их носителям коми языка: «Чолӧм!», «Ме велӧда коми кыв.», «руч» (лиса).

## Если у вас план Starter
- В переменных доступен один режим, поэтому кит без тёмной темы.
- В файле не больше трёх страниц. Если их не хватит, плагин сложит всё на первую страницу.
