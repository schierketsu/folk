# ФОЛК · Android-приложение

Flutter-приложение по макетам ФОЛК для изучения языка и культуры коми. В MVP две темы и шесть заданий.

## Возможности

- Учебный путь с карточкой активного урока, местами «Маньпупунёр» и «Шаньга», наградными сундуками.
- Задания курса, цели с прогрессом, проверка ответов, опыт, клюква и сердца.
- Экран завершения с цикличной анимацией из 20 кадров.
- Лента событий с реакциями, локальными комментариями и копированием текста истории.
- Рейтинг с вашим реальным прогрессом и демонстрационными участниками. Сетевого рейтинга нет.
- Светлая и тёмная темы. Выбор темы и учебный прогресс сохраняются на устройстве.

## APK

Готовый установочный файл: `ФОЛК.apk` (копия `build/app/outputs/flutter-apk/app-release.apk`).

Для повторной сборки: `flutter pub get`, затем `flutter build apk --release`. Текущая release-сборка подписана стандартным отладочным ключом Flutter, подходит для тестовой установки и не предназначена для публикации в магазине.
